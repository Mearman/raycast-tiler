# Window Tiler

Raycast extension that tiles windows into a chosen layout, with include and exclude lists for applications.

## Commands

- **Tile Current App Windows** tiles every window of the frontmost application.
- **Tile Desktop Windows** tiles every window on the active desktop.
- **Manage Tiling Lists** adds applications to the exclude list (never tiled) or the include list (when non-empty, only these are tiled). Exclude wins over include. Applications are matched by bundle ID.

## Layouts

Grid, columns, rows, main and stack, spiral. The active window is placed first, so it takes the main slot in main and stack and the first slot in the spiral. Layout and gap are extension preferences.

## Requirements

The Raycast window management API requires Raycast Pro and macOS. Windows that cannot be moved or resized are skipped and reported.

## Development

```bash
pnpm install
pnpm dev
pnpm test
pnpm lint
pnpm typecheck
```

`typecheck` runs `ray build` first because `raycast-env.d.ts`, which types the preferences, is generated by it and not committed.
